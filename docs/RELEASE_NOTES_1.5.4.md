# Sparring 1.5.4

AI 클라이언트를 정리할 때 StarCraft/BWAPI 오류창이나 오류 로그가 남을 수 있던 문제를 줄인 핫픽스입니다.

## 주요 변경

- 게임 시작 후 AI 클라이언트가 최소화된 상태로 유지되는 흐름을 다시 확인했습니다.
- 연습 종료 정리 중 AI 클라이언트가 닫힐 때 남을 수 있는 StarCraft/BWAPI 종료 오류 로그를 자동으로 정리합니다.
- 오류 정리는 정상 종료 과정에서 생기는 알려진 종료 로그에만 적용되며, 실제 봇 충돌 기록은 남겨 문제 확인에 사용할 수 있습니다.

## 설치 방법

1. StarCraft 1.16.1 원본 클라이언트를 준비합니다. 이미 준비되어 있다면 이 단계는 건너뛰어도 됩니다.
2. `Sparring-1.5.4-setup.exe`를 실행합니다.
3. 설치 프로그램에서 StarCraft 1.16.1 원본 폴더를 지정합니다.
4. 설치가 끝나면 `Sparring` 바로가기로 실행합니다.

## 보안 차단 안내

Sparring은 BWAPI, 오래된 32비트 AI 봇, cnc-ddraw 같은 구성요소를 함께 사용하므로 Windows Defender, SmartScreen, 백신에서 설치 또는 실행 전 확인을 요구할 수 있습니다.

SmartScreen이 표시되면 GitHub Releases에서 받은 설치 파일인지 확인한 뒤 `추가 정보`를 눌러 `실행`을 선택하세요.
