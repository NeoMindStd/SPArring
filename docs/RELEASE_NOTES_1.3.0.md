# StarAI Practice Client 1.3.0

설치 경험을 일반 Windows 프로그램에 가깝게 정리한 마이너 릴리즈입니다.

## 주요 변경

- 새 기본 배포 파일로 `StarAI-PracticeClient-1.3.0-setup.exe`를 제공합니다.
- 설치 프로그램에서 설치 경로를 선택할 수 있습니다.
- 설치 프로그램에서 StarCraft 1.16.1 원본 폴더를 직접 지정하고 파일 유효성을 확인합니다.
- 설치 중 사람 런타임과 AI 런타임을 `C:\starai\SC116AI`, `C:\starai\SC116AI_ai`로 구성합니다.
- 바탕화면 바로가기 생성 옵션을 제공합니다.
- 기존 `C:\starai\Start-StarAI-PracticeClient.cmd` 진입점은 계속 유지합니다.
- 설치 경로를 바꿔도 런처가 자기 설치 폴더의 `data`를 찾도록 보정했습니다.

## 설치 방법

1. StarCraft 1.16.1 원본 클라이언트를 먼저 준비합니다.
2. `StarAI-PracticeClient-1.3.0-setup.exe`를 실행합니다.
3. 설치 경로와 StarCraft 1.16.1 원본 폴더를 지정합니다.
4. 설치가 끝나면 `StarAI Practice Client` 바로가기로 실행합니다.

StarCraft 1.16.1 준비 안내는 아래 링크를 참고하세요.

https://sscaitournament.com/index.php?action=tutorial
