# Sparring 1.5.3

고배율/작은 화면 PC에서 런처 화면이 더 안정적으로 보이도록 다듬은 핫픽스입니다.

## 주요 변경

- 작은 창에서 게임 탭의 래더 후보, 맵 미리보기, 상세 정보 영역이 서로 겹치거나 잘려 보이던 문제를 줄였습니다.
- Hotkeys 탭의 명령 카드와 상세 정보 영역이 compact 화면에서 더 자연스럽게 배치되도록 조정했습니다.
- 런처 하단 상태 문구가 고배율 화면에서 잘려 보이지 않도록 수정했습니다.
- 설치 프로그램 첫 화면의 일부 문구를 더 자연스럽게 다듬었습니다.

## 설치 방법

1. StarCraft 1.16.1 원본 클라이언트를 준비합니다. 이미 준비되어 있다면 이 단계는 건너뛰어도 됩니다.
2. `Sparring-1.5.3-setup.exe`를 실행합니다.
3. 설치 프로그램에서 StarCraft 1.16.1 원본 폴더를 지정합니다.
4. 설치가 끝나면 `Sparring` 바로가기로 실행합니다.

## 보안 차단 안내

Sparring은 BWAPI, 오래된 32비트 AI 봇, cnc-ddraw 같은 구성요소를 함께 사용하므로 Windows Defender, SmartScreen, 백신에서 설치 또는 실행을 확인할 수 있습니다.

SmartScreen이 표시되면 GitHub Releases에서 받은 설치 파일인지 확인한 뒤 `추가 정보`를 눌러 `실행`을 선택하세요.
