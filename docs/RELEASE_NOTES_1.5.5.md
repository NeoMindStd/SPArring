# Sparring 1.5.5

설치와 게임 종료 흐름을 더 안정화한 핫픽스입니다.

## 주요 변경

- 게임 시작 후 AI 클라이언트가 다시 앞으로 올라오는 경우를 줄이고, 스파링 중에는 AI 창이 최소화된 상태를 유지하도록 보강했습니다.
- 정상적인 게임 종료 과정에서 StarCraft/BWAPI 종료 로그가 남아 다음 실행 때 오류처럼 보일 수 있던 문제를 줄였습니다.
- 런처와 설치 화면의 크기 조절, 큰 글꼴, 여러 해상도 표시 상태를 다시 점검했습니다.

## 알려진 사항

- 일부 환경에서는 StarCraft가 종료되거나 오류창이 뜨지 않아도 게임 연결이 끊길 수 있습니다. 이 현상은 계속 추적 중이며, 발생하면 같은 맵과 봇으로 다시 시작해 주세요.

## 설치 방법

1. StarCraft 1.16.1 원본 클라이언트를 준비합니다. 이미 준비되어 있다면 이 단계는 건너뛰어도 됩니다.
2. `Sparring-1.5.5-setup.exe`를 실행합니다.
3. 설치 프로그램에서 StarCraft 1.16.1 원본 폴더를 지정합니다.
4. 설치가 끝나면 `Sparring` 바로가기로 실행합니다.

## 보안 차단 안내

Sparring은 BWAPI, 오래된 32비트 AI 봇, cnc-ddraw 같은 구성요소를 함께 사용하므로 Windows Defender, SmartScreen, 백신에서 설치 또는 실행 중 확인을 요구할 수 있습니다.

SmartScreen이 표시되면 GitHub Releases에서 받은 설치 파일인지 확인한 뒤 `추가 정보`를 눌러 `실행`을 선택하세요.
