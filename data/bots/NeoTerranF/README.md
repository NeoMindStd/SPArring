# NeoTerranF

Sparring 내장 테란 F급 연습 봇입니다. 현재 버전은 학습 모델이 아닌 BWAPI 규칙 기반 봇이며, 선택한 오프닝 빌드를 공급 기준으로 따라간 뒤 보이는 위협과 병력 상황에 따라 수비/생산/공격을 조정합니다.

## 선택 가능 빌드

- vs Zerg: 투배럭 아카데미 바이오, 배럭 더블
- vs Protoss: 팩더블, 투팩 벌처/탱크 압박
- vs Terran: 팩더블, 투팩 압박, 원팩 원스타
- All: 배럭 더블을 기본 운영 빌드로 사용할 수 있습니다.

## 동작 기준

- SCV 생산과 미네랄/가스 배분을 유지합니다.
- 초반 일꾼 견제는 1~2기만 붙이고, 병력이 있으면 SCV를 다시 자원 채취로 돌립니다.
- 큰 초반 위협에는 최대 3기 정도만 동원하고, 생산 건물에서 마린을 우선 확보합니다.
- 병력이 일정 수 이상 모이거나 시간이 지나면 상대 시작 위치로 공격합니다.
- 회복 불가능한 패배 상황에서는 `gg`를 보냅니다.
