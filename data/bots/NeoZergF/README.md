# NeoZergF

Sparring built-in Zerg F-grade practice bot. It is a BWAPI rule-based bot, not a trained model.

## Selectable Builds

- All / ZvZ: Overpool Speed, 9 Pool Speed
- ZvT: 2 Hatch Muta, 530 Muta, Lurker Contain
- ZvP: 3 Hatch Hydra, 5 Hatch Hydra, 9 Pool Speed

## Behavior Notes

- Keeps drone production and basic gas assignment running.
- Pulls only a few drones against early worker harassment, then returns them to mining.
- Uses Zerglings, Hydralisks, Mutalisks, and Lurkers as simple timing/mass attacks.
- Sends `gg` and leaves when it can no longer reasonably fight.
