# NeoProtossF

Sparring 내장 프로토스 F급 연습 봇입니다. 현재는 학습 모델이 아닌 BWAPI 규칙 기반 봇이며, 선택한 오프닝을 먼저 수행한 뒤 초반 난입/치즈/정찰 결과에 따라 단순 운영으로 전환합니다.

## 빌드

- All: 1012 질럿 러시, 빠른 파워드라군
- vs Terran: 23넥 운영, 29아비터, 생더블, 뒤없는 세빠닥, 파도식 전진겟 세빠닥
- vs Zerg: 포지 더블넥, 게이트 더블 커공발닼
- vs Protoss: 생더블, 뒤없는 세빠닥, 파도식 전진겟 세빠닥

## 목표 실력

- 기준: F급 / MMR 950
- 목적: 초보자가 정석 오프닝, 초반 견제, 기본 수비 타이밍을 연습할 수 있는 낮은 난이도 상대
- 한계: 사람처럼 장기 전략을 학습하거나 정교한 마이크로를 수행하지는 않습니다.
